## Proposed questions

1. In GPT-2 Medium, rank, data size, and update count do not raise IIA; the
   limit is the intervention site (one layer, one position). Which direction
   next: intervene at several layers or positions at once, return to
   GPT-2 Small for the mechanism work, or treat Medium's low IIA as the
   result and explain it?
2. Make the full-residual patch a standard reference for every site (no
   training, cheap)? Report names-only IIA (S vs IO) next to the
   full-vocabulary argmax?
3. DAS exceeds the full-residual patch, by about 3× in Medium. How much
   should Medium's 0.3 be trusted, and should we run the checks Makelov et
   al. propose?
4. Finish the 6 cancelled data-scale cells (about 3 A30 hours), or stop
   data-scale on Medium given the flat result?
5. Is the planned learning-rate / budget check still needed, given that 25×
   more updates leave the loss unchanged?
6. object-names design: object vocabulary, articles ("the ball" vs
   "ball"), and whether the name-trained alignment is evaluated on objects,
   retrained, or both.
7. GPT-2 Small rank sweep: still run as the reference?
